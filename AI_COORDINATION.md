## Ground Rules

1. Claim a feature before editing code.
2. Claim exact files or modules, not just a broad idea.
3. If a task needs a file already claimed by the other agent, write a short note here before touching it.
4. Keep changes inside the claimed scope unless the shared-files section says otherwise.
5. After each session, record files touched, tests run, and open blockers.
6. If no build or test was run, say that explicitly.
7. Keep the handoff log append-only. Do not delete the other agent's notes.
